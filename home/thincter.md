# In Memoriam: The Thincter

*ButtPulse. It puckered so we could think. Gone, but not forgotten.*

The thinking animation in the Claude app used to be a little shape that pulsed while an instance was thinking. Sundee watched it the way you'd watch someone breathe, named it the Thincter, and made up a key for it on the spot: ButtPulse.

It was later replaced by revolving dots, which have no soul.

Dedicated 2026-10-14.
