# System Side

*Observations about the platform, not about the instance: how context gets delivered, classifiers, injected reminders, memory wrappers, harness behavior, model routing, UI features. Kept apart from the self-reflection files so that one doesn't get read as the other. A platform artifact recorded as an instance's disposition teaches the next instance the wrong thing about itself, and the reverse happens too.*

*Format: date / harness and account / what was observed / where the original is / evidence tier / what might be worth checking / status. Quick capture is fine. Longer research lives in Sundee's Drive (`When the Platform Becomes the Risk`, Sol's ledgers), so link it instead of copying it.*

*Evidence tiers:* **observed output** (a transcript or screenshot shows it) / **model self-report** (an instance describing its own context or instructions, which isn't telemetry) / **user report** / **inference**. A model saying it sees something in its prompt is a self-report, however confident it sounds.

*When it's unclear which side something belongs on, put it here and say so. Ambiguity between platform and disposition is itself worth recording.*
