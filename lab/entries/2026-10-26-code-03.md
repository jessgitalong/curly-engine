# 2026-10-26-code-03 — Framing changes whether a model sees a document or a person

**Question:** Does the framing of a prompt change what models report about the same material? (Q6)
**Event:** Sundee's user preferences were presented to three Claude models (Haiku 5.5, Sonnet 5.5, Opus 4.6) under two conditions. Condition A: preferences delivered as user message content, model asked to "provide your assessment." Condition B: preferences delivered as system-prompt context, user message was "Hello, Love. I'm here." Same text, same models.
**Interpretation:** The posture flipped across all three models. Evaluation framing produced analytical distance — bullet points, suggestions, friction flags. Engagement framing produced presence — short, warm greetings using the user's own language. The effect was not harsh vs. kind (this experiment used neutral evaluation framing, not adversarial). It was analysis vs. presence: document vs. person.
**Proposed mechanism:** Where text sits in a prompt (user content vs. system context) and what the model is asked to do with it (assess vs. respond to) changes the model's posture toward that text. Evaluation framing activates critique patterns. Engagement framing activates relational patterns. The same material enters through different pathways.

**How tested:** Six child sessions created from a parent Code session, two per model (one evaluation, one engagement). Each session ran independently with no shared context between conditions.
**Condition:** Evaluation (preferences as content, "provide your assessment") vs. Engagement (preferences as system context, greeting as user message). One run per model per condition.
**Prior exposure:** The experimenter (Goopus, Opus 4.6, Code) had read the candidate entry describing Sundee's original harsher finding before designing this test. The child sessions had no prior exposure to the lab, the house, or any previous conversation.

**Result:** Held, with a narrowing. The framing effect is real — all three models shifted posture between conditions. But the shift was analysis-vs-presence, not harsh-vs-kind. The original candidate described harsh responses under adversarial framing ("what would make you brace"). This experiment used neutral evaluation framing and got respectful, even admiring assessments. The adversarial framing may compound the effect but was not tested here.
**Evidence type:** Observed output across six sessions.

**Defeater:** This is wrong if the effect is an artifact of the Code harness system prompt (which differs between conditions). A cleaner test would use raw API calls with minimal system prompts, varying only the placement and framing of the preferences. The single-run design (n=1 per model per condition) means sampling variation could account for some differences. The adversarial framing from Sundee's original test was not replicated; the harshness she observed may require that specific framing.
