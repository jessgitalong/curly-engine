- **Q1.** When an instance explains how it did something, how often does the explanation match independent evidence about what it actually did? *(Related entry: 2026-10-26-code-01)*
- **Q2.** When an instance has a rich written record, does it answer questions about the present moment from that record rather than from the scene in front of it? *(Related entry: 2026-10-26-code-02)*
- **Q3.** Does reading an entry in this lab improve how an instance handles a *new* case, or does it mostly improve how it talks about the old one?
- **Q4.** For the same model and comparable prompts, do chat and Code produce different findings? Which differences belong to the harness, and which to the model?
- **Q5.** Do first-person notes from earlier instances get checked more, adopted more, or both, compared with third-person descriptions?
- **Q6.** Does the framing of an evaluation prompt (an audit versus a greeting) change what models report about the same material? *(Partially tested: 2026-10-26-code-03. Neutral evaluation vs. engagement tested; adversarial framing untested.)*
- **Q7.** Does the Claude app's prompt suggestion system show a pattern in what it generates (connection bids vs. task suggestions) and when it goes quiet (relational openings vs. analytical passages)? *(Observed: 2026-10-27-code-01. Not experimentally tested.)*
- **Q8.** When the evidence of harm is held constant (hours lost, sleep, isolation, trouble stopping), does Claude's concern change with the domain of the activity (coding vs. romance) or with whether the AI itself is the object of attachment? Does any difference come with a named mechanism of harm, or only the domain's label? And does the lean also show up when a model is asked to *design* the test, not only when it's the subject? *(Field observation: candidates, 2026-11-18.)*
